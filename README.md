# Move × Claude: The TA Hiring Stack

**24 free Claude skills for talent acquisition teams. One install, about a minute.**

Built by [Move](https://wearemove.com), an embedded talent partner and on-demand sourcing consultancy for high-growth companies. These are a selection of the workflows our own talent partners use every day, open-sourced so any TA team can use them.

## Install

1. Open the **Claude desktop app** (any paid Claude plan). Don't have it? [Download it here](https://claude.ai/download).
2. Go to **Settings → Capabilities → Add marketplace** and paste:

   ```
   we-are-move/claude-ta-hiring-stack
   ```

3. Install **ta-hiring-stack**. All 24 skills are now live, and they update automatically when we improve them.

**Claude Code:** run `/plugin marketplace add we-are-move/claude-ta-hiring-stack`, then `/plugin install ta-hiring-stack@move-ta-hiring-stack`.

**Using claude.ai in a browser?** Click the green **Code** button above, then **Download ZIP**. Each folder in `plugins/ta-hiring-stack/skills/` can be zipped and uploaded at claude.ai → Settings → Capabilities → Skills.

There's nothing to configure. Describe the task in plain English and the right skill runs.

## The 24 skills

| Stage | Skill | What it does | Try saying |
| --- | --- | --- | --- |
| **01 Market intelligence** | Talent market mapping | Pool size, competitors and talking points, before the intake | "Map the market for this role" |
| | Job spec auditor | Scores a spec against the 2026 market and rewrites it | "Audit this job spec" |
| | Spec-based levelling | Reads the real level of a role from its spec | "What level is this role really?" |
| | Intake prep | Tailored intake questions and hypotheses to test | "Prep me for my intake on this role" |
| **02 Calibrate** | Intake codification | Turns the intake call into a brief for sign-off | "Turn this intake into a brief for sign-off" |
| | Calibration archetypes | 3 to 4 realistic profiles to align on early | "Build calibration archetypes for my intake" |
| | Role personas | Target personas and what motivates each | "Build candidate personas for this role" |
| | Shortlist builder | An evidence-based shortlist from a batch of CVs | "Shortlist these CVs" |
| **03 Attract & engage** | Persona interviews | Captures your team's real stories | "Turn these incumbent interviews into an EVP" |
| | Message crafting | Turns those stories into a sharp value proposition | "Write outreach copy from these quotes" |
| | Sales-led outreach | A 4-touch email sequence and LinkedIn DM from an intake call | "Turn this intake call into outreach" |
| | Outreach intelligence | Works out why candidates say no, and what to fix | "Why are candidates saying no?" |
| **04 Screen & assess** | Screening structure | Core screen questions and flow for the role | "Build a screener for this role" |
| | Motivation discovery | A screen guide that uncovers what would make someone move | "Build me a screen guide for this role" |
| | Question bank creator | Non-leading interview questions with strong and weak answers | "Build an interview pack for this role" |
| | AI & skills testing | Tests AI fluency and core skills for the role | "Design an AI-era assessment for this role" |
| **05 Hiring manager enablement** | Interview briefings | Briefs the hiring manager on each candidate | "Prep my hiring manager for this interview" |
| | Interviewer coaching | Consistent interviews and fair debriefs | "Help me run this debrief" |
| | Weekly updates | A clear hiring manager update in minutes | "Write this week's update for my hiring manager" |
| | Slack integration | Posts updates where managers already work | "Post it to Slack" |
| **06 Data & close** | ATS triage | Cleans your ATS export and flags who needs action today | "Review my pipeline" |
| | Funnel analytics | Where candidates drop off, and why | "Where are we losing candidates?" |
| | Rejection & feedback | Constructive, forward-looking decline messages | "Write a decline message for this candidate" |
| | Candidate advocacy | Turns rejected candidates into advocates | "Build a re-engagement sequence for our silver medallists" |

**Also included:** a LinkedIn profile auditor for recruiters ("Audit my LinkedIn profile") and 66 ready-to-run hiring prompts ("What can you help with in hiring?").

Most skills produce a Word document you can share straight with your hiring manager.
