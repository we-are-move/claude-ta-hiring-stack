# Evaluation Philosophy Template — The Hiring Bar Framework

## How to fill this in

Be specific. Vague answers give vague packs. If asked what raising the bar actually means, do not write "we hire great people." Write "a great hire here ships something meaningful in their first month and changes how at least one process works in their first quarter." The more specific you are, the more precisely the framework can calibrate every question, rubric, and assessment to your bar.

Answer in full sentences where possible. The framework reads these answers as raw material for understanding how your company evaluates.

If you do not know an answer yet, write "we are still working this out" rather than guessing. The framework will work better as your answers sharpen over time. Treat this as a living document and update it whenever your hiring philosophy evolves.

When you have filled it in (or updated it), save the file where Claude can see it — your project folder or the folder you've connected to Claude. The framework will reference it on every pack generation.
